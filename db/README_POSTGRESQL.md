# Manual Menjalankan Aplikasi Versi PostgreSQL

Patch ini sudah mengubah backend dari MySQL (`mysql2`) ke PostgreSQL (`pg`) dan menambahkan file database PostgreSQL di:

```text
backend/db/postgres_init.sql
```

## 1. Syarat yang harus ada

Pastikan sudah terpasang:

1. Node.js versi 18 atau lebih baru
2. PostgreSQL 14 atau lebih baru
3. VS Code
4. Terminal bisa menjalankan perintah `psql`

Cek dengan:

```bash
node -v
npm -v
psql --version
```

## 2. Buka folder project

Buka folder hasil ekstrak ZIP ini di VS Code.

Strukturnya kira-kira:

```text
app_penuh_patch_postgresql/
├─ backend/
├─ frontend/
├─ database/
└─ docs/
```

## 3. Buat database PostgreSQL

Masuk ke PostgreSQL:

```bash
psql -U postgres
```

Lalu jalankan:

```sql
CREATE DATABASE kinerja_pegawai_bps;
\q
```

Jika database sudah ada dan ingin mulai dari awal:

```bash
psql -U postgres
```

```sql
DROP DATABASE IF EXISTS kinerja_pegawai_bps;
CREATE DATABASE kinerja_pegawai_bps;
\q
```

## 4. Import database PostgreSQL

Dari folder utama project, jalankan:

```bash
cd backend
psql -U postgres -d kinerja_pegawai_bps -f db/postgres_init.sql
```

Jika PostgreSQL kamu memakai host lokal eksplisit:

```bash
psql -h 127.0.0.1 -U postgres -d kinerja_pegawai_bps -f db/postgres_init.sql
```

File `postgres_init.sql` akan mengisi tabel dan data awal hasil konversi dari dump MySQL lama.

## 5. Atur file backend/.env

Buka file:

```text
backend/.env
```

Isi minimal seperti ini:

```env
PORT=5000
DB_HOST=127.0.0.1
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=ISI_PASSWORD_POSTGRES_KAMU
DB_NAME=kinerja_pegawai_bps
CLIENT_URL=http://localhost:5173
AUTH_SECRET=ganti-dengan-secret-yang-panjang
```

Catatan:

- `DB_PASSWORD` harus sama dengan password PostgreSQL di laptop kamu.
- Kalau PostgreSQL tidak memakai password, boleh dikosongkan, tetapi biasanya Windows memakai password.

## 6. Jalankan backend

Masuk ke folder backend:

```bash
cd backend
npm install
npm run dev
```

Jika berhasil, backend akan berjalan di:

```text
http://localhost:5000
```

Cek health:

```text
http://localhost:5000/api/health
```

## 7. Jalankan frontend

Buka terminal baru dari folder utama project:

```bash
cd frontend
npm install
npm run dev
```

Frontend biasanya berjalan di:

```text
http://localhost:5173
```

## 8. Akun dummy awal

Akun dummy mengikuti data dari database lama. Beberapa username yang ada:

```text
dummy.superadmin
dummy.admin
dummy.kepala
dummy.kasubbag
dummy.ketuatim
dummy.penilai
dummy.reviewer
dummy.pegawai
```

Password mengikuti data lama di dump. Jika password tidak diketahui, gunakan fitur reset password yang sebelumnya sudah ada di project atau ubah hash password lewat backend sesuai mekanisme aplikasi.

## 9. Perubahan penting dalam patch ini

### Backend

File utama yang berubah:

```text
backend/src/config/database.ts
backend/src/config/env.ts
backend/package.json
```

Backend sekarang memakai package:

```json
"pg": "^8.13.1"
```

dan tidak lagi memakai:

```json
"mysql2"
```

### Database

File baru:

```text
backend/db/postgres_init.sql
backend/db/postgres_foreign_keys_optional.sql
```

`postgres_init.sql` adalah file utama untuk membuat tabel dan memasukkan data.

`postgres_foreign_keys_optional.sql` bersifat opsional. Jalankan hanya kalau ingin mengaktifkan constraint foreign key setelah data berhasil masuk:

```bash
psql -U postgres -d kinerja_pegawai_bps -f db/postgres_foreign_keys_optional.sql
```

## 10. Catatan teknis

Karena aplikasi lama memiliki ratusan query dengan gaya MySQL, patch ini memakai adapter kompatibilitas di:

```text
backend/src/config/database.ts
```

Adapter tersebut mengubah banyak pola MySQL menjadi PostgreSQL saat runtime, misalnya:

| MySQL | PostgreSQL |
|---|---|
| `?` | `$1`, `$2`, dst. |
| `DATE_FORMAT(...)` | `TO_CHAR(...)` |
| `CURDATE()` | `CURRENT_DATE` |
| `NOW()` | `CURRENT_TIMESTAMP` |
| `AUTO_INCREMENT` | `GENERATED BY DEFAULT AS IDENTITY` |
| `ON DUPLICATE KEY UPDATE` | `ON CONFLICT ... DO UPDATE` |
| `GROUP_CONCAT(...)` | `STRING_AGG(...)` |
| `TIMESTAMPDIFF(...)` | `AGE(...)` / ekspresi PostgreSQL |

## 11. Kalau muncul error

### Error: password authentication failed

Berarti `DB_USER` atau `DB_PASSWORD` di `backend/.env` belum sesuai.

### Error: database does not exist

Buat dulu database:

```bash
psql -U postgres -c "CREATE DATABASE kinerja_pegawai_bps;"
```

### Error: relation does not exist

Berarti file SQL belum diimport atau import gagal. Jalankan ulang:

```bash
cd backend
psql -U postgres -d kinerja_pegawai_bps -f db/postgres_init.sql
```

### Error saat query tertentu

Aplikasi lama memakai banyak SQL khusus MySQL. Adapter sudah menangani pola umum, tetapi jika ada halaman tertentu yang masih error, lihat pesan `[PostgreSQL SQL Error]` di terminal backend. Pesan itu akan menampilkan SQL yang perlu disesuaikan.
